MODULE 1: INTRODUCTION TO DBMS & ORACLE ARCHITECTURE 
Question 1: Which of the following is not an advantage of the DBMS? 
(A) User application data creation. 
(B) Data independence and efficient access. 
(C) Reduced application development time. 
(D) Data integrity and security.
Correct Answer: User application data creation.
Explanation: DBMS provides storage, security, and query access, but creating user-level application data is the responsibility of end-users and applications, not an inherent advantage provided by the DBMS engine itself.
Question 2: Which Background process updates the online redo log files with the redo log buffer entries when a COMMIT occurs in the database?
(A) LGWR
(B) DBWn
(C) CKPT
(D) CJQn
Correct Answer: LGWR
Explanation: LGWR (Log Writer) is the Oracle background process responsible for writing redo log buffer entries from memory (SGA) to the online redo log files on disk whenever a transaction COMMIT occurs.
Question 3: Which files can be multiplexed?
(A) Data Files
(B) Control Files
(C) Parameter Files
(D) Data Buffer Cache
Correct Answer: Data Files
Explanation: Data files (as well as control files and online redo log files) can be multiplexed and mirrored across different storage devices to ensure fault tolerance and data recovery.
Question 4: Which Statement about the Data files is not true?
(A) A data file Can belong to only one tablespace 
(B) At least one data file is required for each tablespace 
(C) Maintain the logs of the changes made to the database to enable recovery. 
(D) Data File contains the data in the database, including tables, indexes, temp segments etc 
Correct Answer: Maintain the logs of the changes made to the database to enable recovery. 
Explanation: Maintaining transaction change logs for recovery is the primary responsibility of Redo Log Files, not Data Files. Data Files physically store the actual schema objects like tables and indexes.
Question 5: Which Statement about the Oracle Initialization Parameter Files (init.ora) is not true?
(A) Enclose in quotation marks any parameter value that contains a special character
(B) An initialization parameter file should contain only parameters and comments.
(C) Several parameters can be specified on one line, separated by a space 
(D) Parameters must be specified in a predefined order. 
Correct Answer: Parameters must be specified in a predefined order. 
Explanation: Parameters inside the Oracle initialization parameter file (init.ora / SPFILE) do not need to be specified in any rigid predefined order; Oracle parses them by key-value pairs regardless of sequence. 
Question 6: What is not true about the Oracle Instance?
(A) Oracle Instance provides means to access Oracle database
(B) Oracle Instance is a collection of data that is treated as a unit, which stores and retrieves related information
(C) Oracle Instance can open and use one database at a time
(D) Oracle Instance consists of SGA and background processes
Correct Answer: Oracle Instance is a collection of data that is treated as a unit, which stores and retrieves related information
Explanation: An Oracle Instance consists of memory structures (SGA) and background processes running in RAM. The physical collection of files stored on disk treated as a single unit is the Oracle Database, not the Instance.
Question 7: Which of the following is not a part of System Global Area?
(A) Redo log Buffer
(B) Data Buffer Cache
(C) Parameter Files
(D) Shared Pool
Correct Answer: Parameter Files
Explanation: Parameter files (init.ora / SPFILE) reside physically on disk storage and are read at startup. They are not part of the System Global Area (SGA) shared memory structure in RAM.
Question 8: Which of the following statements about the Data buffer cache is not true?
(A) Data buffer cache stores a collection of the most recently used SQL statements.
(B) Data buffer cache stores the most recently used data
(C) Data buffer cache read and write data to and from the data files
(D) Size of each buffer in the Data buffer cache is equal to the size of an Oracle Block.
Correct Answer: Data buffer cache stores a collection of the most recently used SQL statements.
Explanation: The Data Buffer Cache holds data blocks read from data files. Storing compiled SQL statements and execution plans is the function of the Library Cache inside the Shared Pool, not the Data Buffer Cache.
Question 9: Which of the following statements about the Redo log buffer is not true?
(A) The client process records changes in the redo log buffer
(B) The Redo log buffer records changes made to a database
(C) The server process records changes in the redo log buffer
(D) The Redo log buffer records the block that is changed, the location of the change and the new Value.
Correct Answer: The client process records changes in the redo log buffer
Explanation: Client processes do not directly write into the SGA Redo Log Buffer; the Server Process acting on behalf of the client session writes data changes into the Redo Log Buffer.
Question 10: Which of the following is not stored by the Library Cache?
(A) Results of the SQL statements
(B) The text of SQL statement
(C) The Parse Tree: complied version of a statement.
(D) The Execution Plan
Correct Answer: Results of the SQL statements
Explanation: The Library Cache stores SQL statement text, parse trees, and execution plans. The actual output data or query results are returned to the client session or cached in the Result Cache, not the Library Cache.
Question 11: Which of the following is not true about the Shared Pool?
(A) The shared pool can be used by multiple SQL statements for the processing of data retrieved.
(B) Shared Pool is a part of the SGA
(C) Shared Pool consists of the Library cache and the Data dictionary cache
(D) The shared pool is sized by SHARED_POOL_SIZE parameter of init.ora
Correct Answer: The shared pool can be used by multiple SQL statements for the processing of data retrieved.
Explanation: The Shared Pool stores shared memory structures (Library Cache & Data Dictionary Cache) for statement parsing and execution planning; actual data processing and result set caching occur in the Data Buffer Cache or PGA.
Question 12: Which of the following systems requires a database?
(A) Payroll System
(B) Airline reservations system
(C) A web site that is capturing registered users
(D) All of the above
Correct Answer: All of the above
Explanation: Payroll systems, airline reservation platforms, and user registration portals all require persistent, concurrent, transactional, and structured data storage, making a DBMS indispensable for all of them.
Question 13: Which of the following is not contained in the Program Global Area?
(A) SQL Execution Plan
(B) Session information
(C) Cursor information
(D) SQL execution work areas
Correct Answer: SQL Execution Plan
Explanation: The Program Global Area (PGA) is a private memory region containing session details, cursor state, and sort work areas. SQL Execution Plans are shared resources stored in the Shared Pool (SGA).
Question 14: Which of the following is not a valid level of abstraction in a DBMS?
(A) Tables
(B) Views
(C) Conceptual Schema
(D) Physical Schema
Correct Answer: Tables
Explanation: The standard ANSI/SPARC 3-level DBMS architecture consists of External Level (Views), Conceptual Level (Logical Schema), and Internal Level (Physical Schema). Tables are structural storage objects, not a standalone level of abstraction.
Question 15: Which of the following is not among the ACID properties of a Transaction?
(A) Independence
(B) Atomicity
(C) Consistency
(D) Durability
Correct Answer: Independence
Explanation: ACID properties stand for Atomicity, Consistency, Isolation, and Durability. 'Independence' is not part of the ACID acronym (Isolation provides transaction independence).
Question 16: Which of the following are the advantages of the DBMS over a conventional file system that stores data, in terms of processing power requires a database? 
(A) All of the above 
(B) Ability to create Data Reports 
(C) Efficient Querying of Data 
(D) Matching and Sorting 
Correct Answer: All of the above 
Explanation: DBMS provides centralized data querying, automated report generation, and efficient sorting/matching algorithms, offering massive advantages over flat file systems across all these dimensions.
Question 17: Which of the following is not a valid type of a database management system?
(A) OODBMS (Operations Oriented Database Management System)
(B) NDBMS (Networked Database Management System)
(C) HDBMS (Hierarchical Database Management System)
(D) RDBMS (Relational Database Management System)
Correct Answer: OODBMS (Operations Oriented Database Management System)
Explanation: Valid database models include RDBMS (Relational), HDBMS (Hierarchical), NDBMS (Network), and OODBMS (Object-Oriented). 'Operations Oriented DBMS' is a non-existent category.
Question 18: Which of the following is not a part of the Oracle Database?
(A) Shared Pool
(B) Data Files
(C) Control Files
(D) Redo Log Files
Correct Answer: Shared Pool
Explanation: An Oracle Database consists of physical disk files (Data Files, Control Files, Redo Log Files). The Shared Pool is a memory region in RAM belonging to the Oracle Instance, not the physical database.
Question 19: In an instance, multiple ________ can share an SGA.
(A) Server Processes
(B) PMON Processes
(C) Instances
(D) Databases
Correct Answer: Instances
Explanation: In Oracle Real Application Clusters (RAC) or multi-instance configurations, multiple instances can access a single database, and within an instance, multiple server/background processes share a single SGA memory region.
Question 20: Which component in the following list is not part of the System Global Area (SGA)?
(A) Sort Area
(B) Database Buffer Cache
(C) Library Cache
(D) Shared Pool
Correct Answer: Sort Area
Explanation: The Database Buffer Cache, Library Cache, and Shared Pool are key components of the System Global Area (SGA). The Sort Area is private memory allocated inside the Program Global Area (PGA).

Question 25: Evaluate this SQL statement: SELECT ename, sal, 12*sal+100 FROM emp; The SAL column stores the monthly salary of the employee. Which change must be made to the above syntax to calculate the annual compensation as "monthly salary plus a monthly bonus of $100, multiplied by 12"?

MODULE 3: DATA DEFINITION LANGUAGE (DDL)
Question 41: What does the TRUNCATE statement do?
(A) Removes the table
(B) Removes all rows from a table
(C) Shortens the table to 10 rows
(D) Removes all columns from a table
Correct Answer: Removes all rows from a table
Explanation: TRUNCATE TABLE is a DDL command that quickly removes all rows from a table and deallocates storage space while preserving the table structure. Unlike DELETE, it cannot be rolled back.
Question 42: Which statement about data types is true?
(A) The CHAR datatype should be used for fixed-length character data
(B) The TIMESTAMP data type is an extension of the VARCHAR2 data type
(C) The BLOB data type stores character data up to four gigabytes
(D) The VARCHAR2 data type stores character data up to four gigabytes
Correct Answer: The CHAR datatype should be used for fixed-length character data
Explanation: CHAR is a fixed-length character data type that right-pads values with spaces to the specified length. VARCHAR2 is variable-length and does not space-pad.
